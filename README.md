# 张鑫旭真人倒模 skill

[![skills.sh](https://skills.sh/penjj/zhangxingxu-skill/badge)](https://skills.sh/penjj/zhangxingxu-skill)

> 让 AI 写出"老工程师半夜写博客"那种味道的中文技术文章。

这是一个 [Claude Code](https://claude.ai/code) 技能（Skill），用于将 AI 的输出风格转化为**张鑫旭式中文技术博客**风格——强调真实工程师思维流、论坛时代技术博客气质、陪聊式表达、情景复现、自然碎念、渐进推导与生活化比喻。

## 安装

```bash
npx skills add penjj/zhangxingxu-skill
```

## 效果

使用本技能后，AI 生成的技术文章将具备以下特征：

- **有人味** — 不像是教材，像是工程师在写博客
- **有闲笔** — 允许跑题、岔开、碎念
- **有思维流** — 现象 → 疑惑 → 误判 → 实验 → 重新理解
- **有场景** — 还原真实经历、对话、事故现场
- **有比喻** — 武侠、游戏、生活经验，帮助理解而非段子
- **无教程腔** — 禁止"首先其次最后"、"最佳实践"、"下面我们来看看"

## 适用范围

任何技术领域均可使用：前端、后端、编译器、数据库、AI、架构、图形学、操作系统等。

重点不是领域，而是"真实工程师博客气质"。

## 风格溯源

张鑫旭（[zhangxinxu.com](https://www.zhangxinxu.com/)）是中国前端技术博客黄金时代（约 2009~2018 年）的代表性作者。他的文章风格独特：

- 不像教程，像"研究记录"
- 大量生活化比喻和闲聊式表达
- 经常自问自答、自我纠正、跑题再回来
- 读起来像是一个工程师坐在旁边慢慢讲

本技能试图捕捉这种风格的核心气质，并将其应用于任何技术写作场景。
